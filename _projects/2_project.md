Accepted into IEEE EMBC 2026, under review.

We investigated whether AI-assisted neurofeedback improves attention by integrating a Flutter mobile application with a Muse EEG headband. The app uses an unsupervised Gaussian Mixture Model (GMM) to personalize real-time arousal state classification, pairing it with a GPT-4o-mini AI mentor that delivers spoken guidance via text-to-speech (TTS) during cognitive sessions. Special thanks to Alex Vicol and Xueqi for making this project happen!
